## 一、总路线框架

主路线一句话：**强预训练视觉表征的任务适配 → 全图与原图局部多尺度学习 → 年龄信息融合 → 有验证收益的异构集成。**

阶段闸门 P0→P5：

| 阶段 | 内容 | 当前状态 |
|---|---|---|
| P0 建立比较起点 | 固定数据/划分、归档 Green、CNN 回传校验 | 基本完成，CNN 结果包缺失 |
| P1 全图表征适配 | RFM 全图任务适配 | fold0 完成，缺 fold1/2 |
| P2 多尺度局部建模 | 原图局部取样 + 共享编码 + 注意力 MIL | 实现完成，训练中断无成绩 |
| P3 归因与正式验证 | 主干收益 vs 多视图收益分离 | 未开始 |
| P4 互补集成 | 受约束后融合 | 未开始（仅做过 fold0 事后分析） |
| P5 初赛候选交付 | 全量重训 + 推理 + 提交核验 | 未开始（仅有旧基线提交） |

### 路线 D：集成

- 正式流程（`fuse`，权重在 train OOF 上从 0/.25/.5/.75/1 选）**尚未执行**。

- 残差错误高度共享：最差 100 阳性中，P1 与 Green 重叠 58、与 RFM 重叠 62，三者都判最差 40。

### 候选方案 E：《可行方案1》（仅构思，未实施）

四件套：**视盘定位与尺度归一化 → 原图全图/近局部(3d)/宽局部(5d) → 难阳性排序优化 → 少量互补集成**。

评估结论（`WB/可行方案1可行性评估.md`）：

- 方向对（定位裁图正是"更高分辨率"这条已被识别的 0.99 路径之一），但**量级不够**：预期增量 +0.003~+0.008，而 P1 → 0.99 需要 +0.017。
- 四项机制检验：集成实测上限 +0.0024；残差错误高度共享；**"难阳性分辨率更低"假设不成立**（难阳性 vs 易阳性 Mann-Whitney p=0.329）；official valid 上 0.99 与 0.98 只差 2 个标准误。
- 部署硬约束：T4 ≤100ms、模型 ≤500MB；P1 单视图已 245.6 MiB，三视图 ViT-B 基本不可能达标。
- **重要更正**：榜首是 **0.9902**（原记录"99.02"），不是方案文档里写的 0.998。

## 四、当前卡点（按严重程度）

1. **RFM 预算见底**：账本 19,398.66s / 28,800s，余 **2.61h**；P1 单折 @336 实测 7,073s（1.96h）。补 fold1/2 需约 4h，**装不下**。P2 重跑第一轮也放不下。
2. **P2 无成绩**：局部视图机制（方案 E 的核心前置）从未得到一次完整验证。
3. **CNN 证据缺失**：0.98+ 无法核验，主机无法做完整 OOF 比较和互补分析。
4. **P1 未上 official valid**：目前只有 fold0 内部验证 0.9733，真实线上差距未知。
5. **部署约束未解**：多视图/大主干在 T4 100ms 内基本不可行，尚未做任何压缩或蒸馏验证。

## 六、口径纪律（贯穿全部实验）

- 单折成绩只能同折比较；P1 的 0.9733 与 Green/CNN 的完整 OOF 不可直接排名。
- 开发折参与选轮 → 分数是开发估计，不是独立确认。
- AUROC 增益 <0.002 需第二种子复验。
- official valid 只有 baseline / candidate / delivery 三个里程碑，不反复调参；test 不参与任何拟合。
- 外部标注数据是**赛规禁止**（赛题「4.其他约束」），不是项目自设限制。
